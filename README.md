 Завдання №2
Мета роботи
Ознайомитися з поняттям структур у мові C++, навчитися оголошувати користувацькі типи даних, працювати з масивами структур, а також сортувати та фільтрувати записи за заданими критеріями.
Завдання №2
Створити структуру з іменем `Student`, яка містить поля:
- ПІБ;
- Номер групи;
- Успішність (масив з п'яти елементів).
Написати програму, яка виконує:
1. введення з клавіатури даних у масив, що складається з десяти структур типу `Student`;
2. впорядкування записів у масиві за зростанням середнього балу;
3. виведення на дисплей ПІБ і номерів груп для всіх студентів, які одержують стипендію. Якщо таких студентів немає, виведення відповідного повідомлення.
Опис програми
| Елемент | Призначення |
|---|---|
| `struct Student` | поля `fullName` (ПІБ), `group` (номер групи), `grades[5]` (оцінки) |
| `average(s)` | обчислює середній бал студента |
| `hasScholarship(s)` | перевіряє право на стипендію (немає жодної оцінки нижче 4) |
| `main()` | введення даних, сортування методом бульбашки, виведення результатів |
